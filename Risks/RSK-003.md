## Beschrijving

### Risico Scenario

Onvolledige of ontbrekende audit logging maakt het onmogelijk om security incidents te detecteren,
te onderzoeken of te bewijzen wie wat wanneer heeft gedaan.

### Impact Analyse

| Impact Type | Beschrijving |
|-------------|--------------|
| **Operationeel** | Beperkte incident response mogelijkheden |
| **Financieel** | Hogere onderzoekskosten bij incidents |
| **Reputatie** | Verminderd vertrouwen van toezichthouders |
| **Compliance** | Schending AVG Art. 30, BIO2 8.15 |
| **Veiligheid** | Geen forensische mogelijkheden |
